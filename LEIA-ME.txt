COMPASSO 1.1 — INSTALAÇÃO E ATUALIZAÇÃO

1. IMPORTANTE: no Compasso antigo, vá a Perfil > Backup JSON e salve uma cópia antes de atualizar.
2. Extraia o ZIP e envie os 7 arquivos à RAIZ do mesmo repositório usado no GitHub Pages.
   Não envie apenas o ZIP; renomeie/substitua os arquivos antigos pelos nomes exatos do pacote.
3. Não altere a URL publicada: os dados do navegador dependem da origem do site.
4. No GitHub Pages, aguarde a publicação, acesse o endereço HTTPS e atualize a página.
5. Android: menu do Chrome > Instalar aplicativo (ou Adicionar à tela inicial).
   iPhone: Safari > Compartilhar > Adicionar à Tela de Início.
6. Se o atalho anterior ainda se chamar NekoQuest, exporte o backup antes de reinstalar.
   Não use 'Limpar dados' no navegador sem ter uma cópia do backup.
